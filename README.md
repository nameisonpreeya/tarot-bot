# 🔮 LINE Tarot Bot (MySQL Powered)

> บอท LINE สำหรับดูดวงไพ่ทาโรต์ ใช้งานได้ฟรีตลอดชีพโดยไม่ต้องพึ่งพา AI API ช่วยเลี่ยงปัญหาโควต้าหมด (Error 429) ขับเคลื่อนด้วย Node.js, Express.js และฐานข้อมูล MySQL

---

✨ ฟีเจอร์เด่น (Features)
- ☀️ **ดวงประจำวัน (1 ใบ):** สุ่มหยิบไพ่รายวันพร้อมคำทำนายและสถานะหัวตั้ง/กลับหัว
- 🔮 **ดูดวงเจาะลึก (3 ใบ):** เปิดไพ่ทำนายแบบ อดีต - ปัจจุบัน - อนาคต สำหรับคำถามทั่วไป
- 🗄️ **Database Driven:** ดึงข้อมูลความหมายไพ่ทั้งหมดจาก MySQL รวดเร็ว ปลอดภัย และฟรี 100%
- 🎨 **Rich Menu Support:** รองรับการใช้งานผ่านปุ่มเมนูลอยใน LINE OA ใช้งานง่าย ไม่ต้องพิมพ์คำสั่งยาวๆ

---

🛠️ Tech Stack
- Backend: Node.js, Express.js
- Database: MySQL (`mysql2/promise`)
- Messaging API: `@line/bot-sdk`
- Hosting / Deployment: Railway
